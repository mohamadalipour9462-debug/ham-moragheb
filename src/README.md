
# هم‌مراقب | Ham-Moragheb

پلتفرمی فارسی برای کمک به خانواده‌ها در پیدا کردن خدمات مراقبت روزانه و غیرپزشکی سالمندان.

## هدف پروژه

ساخت بستری ساده و قابل‌اعتماد برای ارتباط خانواده‌ها، مراقبان مستقل و مراکز خدمات مراقبتی.

## قابلیت‌های نسخه اولیه

- رابط کاربری فارسی و راست‌چین
- جست‌وجوی مراقبان بر اساس شهر و نوع خدمات
- نمایش کارت‌های نمونه مراقبان
- فرم آزمایشی درخواست خدمات
- طراحی واکنش‌گرا برای موبایل و کامپیوتر

## فناوری‌ها

- React
- Vite
- JavaScript
- CSS
- Git و GitHub

## اجرای پروژه در محیط محلی

پیش‌نیاز: نصب Node.js نسخه LTS

```bash
npm install
npm run dev
```

سپس آدرس محلی نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید.

## وضعیت پروژه

نسخه اولیه در حال توسعه است. اطلاعات مراقبان آزمایشی هستند و فرم درخواست هنوز به سرور متصل نیست. احراز هویت، پایگاه داده، پرداخت و رزرو واقعی در نسخه فعلی پیاده‌سازی نشده‌اند.

## حریم خصوصی و اعتماد

اطلاعات شخصی واقعی نباید در داده‌های آزمایشی یا مخزن عمومی قرار بگیرند. پیش از ارائه خدمات واقعی، فرایند بررسی هویت مراقبان، حفاظت از اطلاعات و رسیدگی به شکایت‌ها باید طراحی شود.
